# Security policy

CAAS is a Claude Code plugin and a Claude Desktop extension. Once installed, it runs code on your machine with your user permissions. If you find a weakness, please tell us privately first.

## How to report

Use GitHub's private reporting: open the **Security** tab of this repository and press **Report a vulnerability**. Only the author can read your report. You do not need to share an email address.

Please do not open a public issue for a weakness until it is fixed.

## Supported versions

Only the latest release is fixed. Older releases stay available but are not updated.

## What to include

- The version (release tag) you used
- What you did, what happened, and what you expected
- Whether the weakness lets the chat reach anything beyond the tray folder and the sessions it may message

# 弱点の知らせ方

CAAS は Claude Code のプラグインと Claude Desktop の拡張機能です。入れると、あなたのパソコンで、あなたの権限でプログラムが動きます。弱点に気づいたら、まず内密に知らせてください。

- **知らせ方**：この置き場の **Security** タブを開き、**Report a vulnerability** を押してください。知らせは作者だけが読めます。メールアドレスを出す必要はありません。直るまでは、誰でも見られる Issue に書かないでください。
- **直す版**：いちばん新しいリリースだけを直します。前の版は残しますが、直しません。
- **書いてほしいこと**：使った版（リリースの札）／したこと・起きたこと・起きると思っていたこと／その弱点で、チャットがトレイのフォルダと話しかけてよい席より先へ届いてしまうかどうか
